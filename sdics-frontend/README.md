# SDICS Frontend - React + TypeScript

Modern React + TypeScript frontend for SDICS (Strategic Digital Identification & Campaign System).

## Setup

```bash
npm install
npm run dev
```

Build:
```bash
npm run build
npm run preview
```

## Architecture

- React 19 + TypeScript
- Vite for fast development
- React Router for navigation
- Tanstack Query for server state
- Material UI for components
- Zustand for auth state management
- Axios with JWT authentication
